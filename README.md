# Browserspiele

Zwei kleine Browserspiele, umgesetzt mit dem KI-Coding-Agenten
[Claude Code](https://www.anthropic.com/claude-code).

## ▶ Direkt spielen

| Spiel | Link |
|---|---|
| Tic-Tac-Toe | [Spielen](https://taanel.github.io/browserspiele/tic-tac-toe/tic-tac-toe.html) |
| Top-Down-Shooter | [Spielen](https://taanel.github.io/browserspiele/top-down-shooter/top-down-shooter.html) |

Läuft direkt im Browser, keine Installation nötig.

## Entstehung

Beide Spiele sind per Prompting mit Claude Code entstanden.

**Meine Rolle:**
- Anforderungen und Spielregeln formuliert
- Ergebnisse im Browser getestet
- Fehler und Verbesserungen an den Agenten zurückgemeldet und iterativ nachgebessert

Den Code selbst hat der KI-Agent geschrieben.

## Aufbau

Jedes Spiel besteht aus einer einzelnen HTML-Datei (HTML, CSS und JavaScript in einer Datei).
